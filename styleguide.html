01

Color

Two tiers. Tier 1 is the raw palette, named for what each color is. Tier 2 binds those to semantic roles, named for what each color does. Everything downstream references the roles, never the hex values — so a dark mode or a print sheet is a ten-line rebind rather than a rewrite.

--pa-globe-blue

#1D3F6E

The navy of the 1957 globe mark. Primary brand color: nav bar, display type, the globe itself.

--pa-powder

#A8C6DF

Cabin and ticket-jacket blue. A surface color for large calm fields. Never a text color — see rule 2.

--pa-sky

#DCE8F2

Powder tinted up, for surfaces that need separation without reading as a colored block.

--pa-paper

#F4F1EA

The most important token here. A pure white page reads as modern software. Warm paper stock reads as 1960s ticket card, and carries the period work the rest of the palette is doing.

--pa-white

#FFFFFF

Held in reserve for cards and tickets sitting on paper, so they lift off it.

--pa-ink

#14181D

Body text. Not pure black: #000 on a warm ground optically vibrates and reads harsher than it measures.

--pa-ink-muted

#4E5A68

Secondary text. Desaturated navy rather than grey, so quieter text reads as quieter, not as a different material.

--pa-stamp-red

#B3242B

The only accent. Pan Am was blue-and-white almost exclusively; red appeared as stamps and cancellation marks. Strictly rationed — see rule 1.

Contrast, measured

WCAG AA needs 4.5:1 for normal text and 3:1 for large text. These are the real ratios for every pairing the system permits — plus the one it forbids.

Ink on paper — body text 15.8:1 AAA
White on globe blue — nav, inverted bands 10.6:1 AAA
Ink on powder — cover field 10.0:1 AAA
Muted ink on paper — captions 6.2:1 AA
Stamp red on paper — active state 5.8:1 AA
Powder as text on paper — the mistake this palette invites 1.6:1 FAILS

02

Type

Stack: "Helvetica Neue", Helvetica, Arial, "Liberation Sans", sans-serif. Pan Am's 1957 identity was one of the first major corporate uses of Helvetica. No webfont is loaded: macOS has Helvetica Neue, Windows has Arial and Linux has Liberation Sans, and those last two are metrically identical to Helvetica — same character widths, subtly different letterforms. So every visitor gets the right measure for zero network requests and zero layout shift. A font already on the machine always beats one you download.

The two largest steps use clamp(), so they scale continuously between a floor and a ceiling instead of jumping at breakpoints. Resize this window and watch the display line move. Media queries are saved for layout, where a discrete switch is genuinely what you want.

Cargo schedule

The cover step. Not a bigger heading — a graphic element that happens to be readable. On the Pan Am cargo schedule cover the title spans the whole sheet and all but touches both edges, and that scale is most of why the thing still looks confident sixty years later. Two things make it work and both get skipped: line-height below 1, so the lines nearly touch and read as one mass, and tracking at −0.04em, because letterforms carry too much optical space at this size and look loose at default spacing.

The load-bearing step. Tiny, bold, uppercase, widely tracked — this single treatment is the whole visual signature of airline signage, boarding passes and departure boards. It is what will make the About page read as manifest data rather than as a stack of headings. Most of the distinctly Pan Am moments on this site will be this one class.

03

Spacing

A 4px base on a deliberately non-linear ramp. Useful spacing values cluster at the small end — you need 4, 8, 12 and 16 as genuinely distinct choices — and spread at the large end, where nobody needs both 96 and 104. A strictly linear ramp wastes half its steps. The names are numeric rather than t-shirt sizes because --space-5 has an obvious neighbour in both directions, where --space-lg does not tell you whether --space-xl comes next or whether someone will eventually add --space-lg-plus.

The stack, applied

Vertical rhythm comes from one mechanism, not from margins scattered across every element.

The selector is .stack > * + * — "every child that follows another child."

So the first child never gets a top margin, and a stack never adds stray space at its own top edge. Compare the usual approach of putting margin-bottom on every paragraph, which always leaves a margin hanging off the last one that you then strip with a :last-child rule.

04

Grid

Twelve columns, 1200px maximum measure, gutters from the spacing scale. Full-width color bands are achieved by putting a .container inside a full-bleed .band, which is how you get edge-to-edge color without breaking content alignment.

One substitution worth knowing: the tracks are minmax(0, 1fr), not plain 1fr. A bare 1fr has an implicit minimum of auto, so one long unbreakable string — a URL, a wide table — can force its track past its share and blow out the whole grid. This is the most common CSS Grid bug and that is the entire fix.

Column count is a genuinely discrete decision — there is no meaningful "3.4 columns" — so a hard switch is the right tool here, where clamp() was the right tool for type. 05

The globe

Defined once as an SVG <symbol> and referenced with <use>. It strokes with currentColor, so one definition serves navy-on-paper and white-on-navy with no second file — an <img> could not do this, because an image cannot inherit CSS color.

How the geometry works. Viewed head-on, latitudes project to horizontal chords: a latitude at angle f sits at y = 50 − 46 sin f with half-width 46 cos f. Meridians project to ellipses sharing the vertical radius, with horizontal radius 46 cos (longitude) — 0 at the centre (a straight line), 23, 39.8, and finally 46, which is the outer circle itself. Each ellipse draws the front and back halves of one meridian pair at once. That ellipse trick is what makes a flat circle read as a sphere, and it is exactly what the original mark does.

The mark has always had two lives: a solid navy disc on aircraft tails and ticket jackets, readable at two hundred metres, and fine line art sitting quietly beside the wordmark on a printed schedule. Same geometry, two different jobs. Both come from one symbol — the disc is a circle whose fill reads --globe-fill, defaulting to none, so the badge variant just fills it and flips the text color. No second symbol, no second file.

The lockup

Wordmark and globe set as one unit. The globe sits at roughly cap height beside the word — and it is sized in em, not from the --icon-* scale, so that relationship holds at every size with no per-instance fiddling. Tie an icon to the font size of the text it sits beside and it stays optically correct forever; give it a fixed pixel value and you will be nudging it on every page.

The --simple, --hairline and --heavy variants are driven by custom properties, not ordinary selectors. This is worth knowing: <use> clones the symbol into a shadow tree, and a rule like .globe--simple .globe__detail { display: none } cannot reach inside it — it silently does nothing. Custom properties do inherit across that boundary, so the symbol declares style="display: var(--globe-detail, inline)" and the variant class flips the variable. That is the standard escape hatch for styling <use> content.

An original geometric construction in homage to the 1957 mark, not a traced reproduction. Fine for a personal site; worth a second look before any commercial use, since the mark is still held.

06

The manifest primitive

This is the piece that decides whether the About page works. Its three sections — a flag row, an experience manifest and a hobbies row — have to read as one designed system rather than three widgets that happen to share a typeface. The way to guarantee that is to build them from a shared primitive now, before any content exists, instead of styling them separately later and hoping they match.

The abstraction is a cell, not a row. Every entry is [ mark ][ year ][ one-line fact ], and the modifiers only change how those three parts are arranged. Both read the same local tokens, so retuning the mark size or the rule color updates all three sections at once. The content below is placeholder — real content arrives in step 3.

.manifest--strip

Items side by side, parts stacked. This becomes the flag row. It reflows from six across to two across with no breakpoints at all — auto-fit plus minmax() lets the grid work out how many fit, and you only state the minimum width an item needs to stay readable.

07

Document types

Pan Am did not print one layout four times. A ticket jacket, a cargo schedule, a boarding pass and a baggage tag look nothing alike — yet nobody could mistake which airline issued them. What holds them together is the globe, Helvetica, the rule grammar and the palette. Not a shared layout.

So each page gets its own document type instead of a common template. They share every token and no structure, which is the difference between a design system and a template. Each preview below simply rebinds the type tokens on a wrapper to scale down — not one component rule was changed to make them fit, and there is no "small variant" of anything to maintain.

08

Design rules

A design system is a vocabulary plus rules for using it. Tokens alone will not stop the site drifting, because every drift is individually reasonable. These are written down here, in prose, because they cannot be expressed as CSS — and an unwritten rule is one you will break without noticing.

Rule 01 — Ration the red

--pa-stamp-red appears at most twice per page: typically the active nav state, and one stamp mark. Historically Pan Am was blue-and-white almost exclusively, with red reserved for stamps and cancellation marks. A restrained palette used unrestrainedly stops being restrained — and red is the token most likely to creep, because each individual use always feels justified.

Rule 02 — Powder is a surface, never text

--pa-powder and --pa-sky are background colors only. Powder text on paper measures 1.6:1 against a 4.5:1 requirement — see the contrast table above. This is the specific mistake this palette invites, because powder on paper looks pleasant at display sizes and becomes unreadable at body sizes.

Rule 03 — Never reach past the semantic layer

Outside tokens.css, write var(--color-text), never var(--pa-ink) and never #14181D. The moment a raw palette token is used directly in a component, the two-tier system stops working and a theme change becomes a find-and-replace across every file.

Rule 04 — New layout CSS on a content page is a smell

If building a page requires new structural CSS, the primitive was underspecified — fix the primitive, do not add a page-specific override. Overrides are how a design system quietly becomes four unrelated stylesheets. Step 3 is the real test of this: the About page should need essentially no new layout rules.
